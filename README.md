# marivallarelli.github.io

Personal portfolio showcasing AI, Data Science, LLMOps, publications, talks, and open-source projects.

## Local preview

The published homepage is [`index.html`](index.html). To preview it locally, run:

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000>. Push changes to the default branch to publish them with GitHub Pages.
